## Watching and sharing

These public GitHub and direct MP4 links can be shared without cloning the repository or signing in. GitHub's repository file viewer may show **View raw** instead of a player. The direct URLs serve the original files; browsers may download them because GitHub sends `application/octet-stream`. Open the downloaded MP4 in a compatible browser or video player. For LinkedIn, Medium, Dev.to, or a portfolio, share the repository/video links above, or upload the original MP4 where that platform supports video. A direct MP4 link does not guarantee that another platform will generate an inline preview.

Both videos include an English subtitle stream. The full film also has captions burned in; V2 uses prominent scene text with optional subtitles. Standalone SRT files are provided for platforms that support caption uploads. Neither version has a voiceover.

## Accuracy, privacy, and reuse

Hazlo uses browser speech recognition where supported and local, rule-based task extraction. Entries are saved in browser storage and can be sent through a Vercel Function to a configured Notion data source. Users can fork the MIT-licensed project and deploy a personal instance; it is not a full multi-user SaaS platform.

Some motion graphics are illustrative. The waveforms are not claimed as live microphone recordings. Successful Notion flows/pages are labelled illustrative; the capture harness blocks production sync requests, so no live Notion success is claimed. Captures contain fictional tasks and no credentials or personal workspace content.

Both scores and sound effects are original procedural compositions. See the [media provenance](../../tools/promo-video/MEDIA-LICENSE.md), [V2 music license](../../tools/promo-video/v2/MUSIC-LICENSE.md), and repository [MIT License](../../LICENSE).
